## 👨‍💻 About Me
I am a **Software Engineer** with a deep-rooted foundation in Backend systems (Go, Python, .NET). Currently, I am expanding my horizons as a **Fullstack Engineer**, merging high-concurrency backend logic with modern, type-safe frontend experiences using **Next.js**, **TypeScript**, and **Tailwind CSS**.

- 🔭 **Current Focus:** Elevating fullstack performance with Next.js App Router & Server Actions.
- ⚡ **Strengths:** Architecting for scale, distributed locking, and event-driven workflows.
- 🎯 **Philosophy:** "Build systems that survive real-world traffic — not just pass local tests."
